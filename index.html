FAQ

Is this official?

No. It is an unofficial fork of the open-source Bitwarden clients, not affiliated with Bitwarden Inc.

Which APK do I need?

Most phones since 2017 need arm64-v8a, and the button above picks for you. Older 32-bit phones: armeabi-v7a. Emulators and Chromebooks: x86_64.

Does it replace the official app?

No. The app id is com.x8bit.bitwarden.patched, so both install side by side. You sign in with your normal account.

What is patched?

The client-side premium check, plus name, app id and logo badge. Encryption, networking and sync are untouched, and anything the server enforces still follows your plan. Patch list.

Is it allowed?

The clients are GPL-3.0, so modifying and redistributing them is permitted. Bitwarden's hosted service has its own terms; self-hosting is the intended setup.

Why no one-click install on Chrome?

Chrome, Brave and Edge only install outside-store extensions in developer mode. Firefox installs the signed add-on directly.
