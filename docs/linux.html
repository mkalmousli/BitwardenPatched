Linux packages

Unofficial patched Bitwarden clients. What changes? Patch source.

Debian, Ubuntu and Mint

Download a .deb from the desktop release and install it with sudo apt install ./package.deb.

Maintainers can enable the signed rolling APT channel described below. It is available only after a maintainer configures signing and publishes the first repository release.

  1. Download archive-keyring.gpg from the rolling APT release. Verify its full fingerprint with gpg --show-keys --with-fingerprint archive-keyring.gpg against the maintainer's independently published fingerprint.
  2. Install it: sudo install -m 644 archive-keyring.gpg /usr/share/keyrings/bitwarden-patched.gpg.
  3. Save this source as /etc/apt/sources.list.d/bitwarden-patched.list: 
    deb [signed-by=/usr/share/keyrings/bitwarden-patched.gpg] https://github.com/mkalmousli/BitwardenPatched/releases/download/rolling-apt/ ./
  4. Run sudo apt update, then sudo apt install bitwarden-patched.

Packages and signed indices are release assets, so they do not enlarge the Git repository.

Fedora, RHEL and openSUSE

Download the matching .rpm. Install with sudo dnf install ./package.rpm or sudo zypper install ./package.rpm. RPMs use release checksums; this project does not currently publish a signed DNF/Zypper repository.

Arch and other distributions

Use the matching AppImage (chmod +x file.AppImage, then run it) or extract the Linux tar.gz. AppImages may need your distribution's FUSE compatibility package. Choose x64 for Intel/AMD or arm64 for ARM. These downloads require manual updates.
