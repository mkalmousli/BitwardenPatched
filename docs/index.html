Browser extension (self-updating)

Firefox: open the .xpi below and click Add; it updates itself.
Chrome / Edge / Brave: the .crx updates itself from chrome/updates.xml. Chrome on Windows/macOS only accepts off-store CRX files through an extension policy; on Linux, drag the file onto chrome://extensions. The zip works everywhere as "Load unpacked" but does not self-update.

What is patched

  • Client-side premium check always on (built-in TOTP and other local features), Android and browser.
  • Own name and app id plus a fork badge on the original logo, so it installs next to the official app.
  • Own update channels (F-Droid repo, Firefox and Chrome update manifests).

Nothing else is changed. Full list with explanations. Version numbers match upstream Bitwarden.

Good to know

Installs next to the official app (separate app id). Server-enforced features still depend on your plan. Self-hosted servers (Bitwarden or Vaultwarden) are the intended setup. Not affiliated with Bitwarden Inc. GPL-3.0. Source and details on GitHub.

Browser zips: Chrome/Edge/Brave via chrome://extensions → Developer mode → Load unpacked (unzip first); Firefox via about:debugging → Load Temporary Add-on.
