Good to know

Installs next to the official app (separate app id). Server-enforced features still depend on your plan. Self-hosted servers (Bitwarden or Vaultwarden) are the intended setup. Not affiliated with Bitwarden Inc. GPL-3.0. Source and details on GitHub.

Browser zips: Chrome/Edge/Brave via chrome://extensions → Developer mode → Load unpacked (unzip first); Firefox via about:debugging → Load Temporary Add-on.
