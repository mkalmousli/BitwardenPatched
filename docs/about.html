Bitwarden PatchedDownloads

A patch layer on Bitwarden.

This project downloads official Bitwarden source, applies a small published set of patches, and builds unofficial clients. It is not an independent password manager and is not affiliated with or endorsed by Bitwarden Inc.

What changes?

Client-side premium checks are enabled, including built-in TOTP. Apps use a distinct name, application ID and fork badge. Android builds are split by CPU architecture.

Encryption, login, networking and sync code are not patched. Features enforced by the server still follow your account plan. Self-hosted Bitwarden or Vaultwarden is the intended setup.
